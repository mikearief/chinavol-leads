# ChinaVol Landing Proposal Mockups

Created for visual review only. These files do not modify the live `index.html`.

## Files

- `landing-v1-command-center.html` - operational homepage focused on live risk proof and signal widgets.
- `landing-v2-newsroom.html` - editorial homepage with a stronger headline and "moving now" side rail.
- `landing-v3-volatility-lab.html` - chart-first homepage that leans hardest into the ChinaVol identity.
- `landing-v4-integrated-suite.html` - navbar-led IA that keeps all three directions as product sections.
- `mock-data.json` - sample fixture behind the concepts.

## Recommendation

Start from Proposal D if the goal is a full site direction: Today becomes the command center, Newsroom handles the editorial surface, and Volatility becomes the chart/product lab. If choosing a single homepage only, Proposal A remains the strongest first screen.
